## 1. 模块结构

```text
frontend/
├─ contexts/
│  └─ AgentContext.tsx        # 全局 Agent 状态（单一会话事实源）
├─ lib/
│  ├─ agent-client.ts         # 纯数据层：请求组装 / fetch / 信封归一化
│  ├─ action-bus.ts           # 动作分发：同页执行 / 跨页待确认 / 确认后导航
│  ├─ action-navigation.ts    # 动作 → 深链接（/timeline?event=… 等）
│  └─ routes.ts               # 深链接构造器（新增 timeline group 参数）
├─ components/agent/
│  ├─ AgentProvider.tsx       # 兼容层：re-export contexts/AgentContext
│  └─ AgentDrawer.tsx         # 提问 / transcript / 跨页动作确认按钮（视觉待细化）
├─ app/
│  ├─ timeline/page.tsx       # 已注册 timeline.focus_event / focus_dynasty handler
│  └─ graph/page.tsx          # 已注册 graph.focus_person / focus_relation handler
└─ tests/
   ├─ agent-client.test.ts    # 数据层 19 条
   ├─ action-navigation.test.ts # 动作 → URL 7 条
   └─ action-bus.test.ts      # 分发 / 导航 / 批量 15 条
```

## 2. 调用链

```text
AgentDrawer 提交问题
  └─ AgentContext.ask(question)
       ├─ buildAskRequest：question + context(route/mode/dynasty/era/event/person_id) + history(最近 10 轮)
       ├─ postAsk：POST /api/agent/ask（同源 next rewrite → FastAPI:8000）
       ├─ AnswerEnvelope → AgentAnswerView（markdown / certainty / missing / citations / entities / ui_actions）
       ├─ transcript 追加 user + assistant turn
       └─ actionBus.dispatchAll(ui_actions 加 request_id 前缀)
            ├─ 同页（target.surface === 当前页）：执行页面 handler（自动跳转 / 打开事件卡）
            └─ 跨页：进入 pendingActions → 抽屉渲染确认按钮
                 └─ confirmAction(id) → 无 handler 时 navigate(hrefForAction(action))
```

## 3. 关键约定

| 项 | 约定 |
|---|---|
| 会话 | 单一 `AgentContext`；`session_id` 每个浏览器会话生成一次；`history` 过滤欢迎语 / 错误提示，最多 10 轮、单条 4000 字 |
| 页面上下文 | `route` 取当前 pathname；`mode` = query `mode=detail` → detail，否则 browse；`event_id` / `dynasty` / `era_id` 取 query；`person_id` 仅当 query `person` 是稳定 `p-` ID |
| 动作幂等 | 服务端动作 id 每轮可能重复（如 `act-1`），前端统一加 `request_id:` 前缀后再进入 ActionBus |
| 同页 / 跨页 | 由 `decideAction(action, currentSurface)` 判定，**不信任后端 `auto`**；跨页一律确认 |
| 跨页导航 | `hrefForAction`：focus_event → `/timeline?event=`；focus_dynasty → `dynasty|group`；focus_person → `/graph?person=`；focus_relation → `/graph?person=&selected=`；ask.suggest → `/ask?q=` |
| 错误 | 后端 `ErrorEnvelope` 原样展示 `error.message`；网络 / 非 JSON 异常转中文提示，不抛到渲染层 |
| 安全 | 前端只展示服务端 `answer.markdown`；不拼接、不改写模型文本 |

### 4.2 手工验收（真实模型）

1. 双击仓库根 `启动史脉.cmd`（自动拉起 FastAPI:8000 + Next:3000；`backend/.env` 需有 `MODELSCOPE_API_KEY`）。
2. 打开 `http://localhost:3000/timeline`，点右下角「问史脉」，提问：**「赤壁之战发生在哪一年？」**
   - 期望：服务端返回 grounded 回答；若回答带 `timeline.focus_event`，时间轴自动切到东汉、选中赤壁之战，URL 变为
     `/timeline?event=handong-chibi&dynasty=东汉&mode=detail`。
3. 打开 `http://localhost:3000/graph`，提问：**「周瑜是谁？」**
   - 期望：若返回 `graph.focus_person`，图谱自动以对应人物为中心，URL 变为 `/graph?person=…`。
4. 在**首页** `/` 提问时间轴 / 图谱问题：
   - 当前 surface 为 `null`，动作判为跨页 → 抽屉出现「前往 / 取消」按钮；
   - 点「前往」→ 跳转到目标页深链接并恢复视图；点「取消」→ 动作丢弃。
5. 提问：**「明朝的 GDP 是多少？」**
   - 期望：`insufficient` / `refusal`，正文为服务端固定文案，无编造数字、无 UI 动作。
6. 连续问两轮，确认第二轮历史被带入且动作 id 不因跨轮复用被误判为重复。

### 4.3 手工验收（离线 / 不调模型）

- 打开抽屉输入任意问题，若后端未启动 → 抽屉显示「无法连接史脉服务，请确认后端已启动」。
- 纯前端逻辑可用 `frontend/tests` 单测覆盖（ActionBus 导航、请求组装、信封归一化）。

## 5. 边界（本卡不做）

- AgentDrawer 的视觉重设计、来源卡片 / 引用展开、错误态视觉；
- `/ask` 独立页与 `/ask?q=` 自动提问；
- `ask.suggest` 建议问题列表（V1.0.6）；
- `timeline.highlight_events` / `graph.highlight_persons`（planned）。
