## 0. 结论

- 8 个工具全部基于**内存快照**实现，不发起 HTTP、不访问数据库、不写盘；
- 每个工具返回**统一信封**：`ok / tool / items / citations / truncated / snapshot_version / data / error / meta`；
- `tools-v1.schema.json` 的 `output` 已是统一信封（成功 / 失败 `oneOf`），`data` 保持 V1.0.1 的工具专属出参；单测逐工具用 JSON Schema 校验**整个返回**；
- 空结果与错误有明确语义：查无 → `total=0`；实体不存在 → `ok=false` + `ENTITY_NOT_FOUND`；入参非法 → `INVALID_REQUEST`；

## 1. 目录与调用方式

```text
backend/agent/
├─ __init__.py
└─ tools/
   ├─ __init__.py        # TOOL_NAMES / TOOL_FUNCTIONS / call_tool / Toolkit
   ├─ base.py            # ToolContext、统一信封、引用构造、入参校验

   ├─ relations.py       # get_relation
   └─ graph.py           # get_era_graph
```

V1.0.3 规划器只需构造一次 `Toolkit`：

```python
from agent.tools import Toolkit

toolkit = Toolkit(app.state.store)          # 启动时构造一次，内部持 ToolContext
result = toolkit.call("search_events", q="赤壁", dynasty="东汉")
result["ok"], result["data"]["events"], result["citations"]
```

单测可直接调函数（`ctx` 为第一个参数）：

```python
from agent.tools import ToolContext, get_event

ctx = ToolContext.from_store(store)
result = get_event(ctx, event_id="xixia-09")
```

## 2. 统一返回信封

`contracts.models.ToolResult` 在 V1.0.2 **只新增可选字段**（符合 `contracts/README.md` §3 版本规则），旧调用方不传新字段仍然可用。
经产品批复，`contracts/tools.py` 的 `output` 已同步升级为统一信封（`oneOf` 成功 / 失败两个变体），并由 `export_contracts.py` 重新导出：

| 字段 | 类型 | 说明 |
|---|---|---|
| `ok` | bool | 成功 / 失败 |
| `tool` | str | 工具名（schema 用 `const` 锁定） |
| `items` | list | **主结果列表**：与 `data` 的主结果一致（对象型结果包一层单元素列表） |
| `citations` | list[Citation] | 结构化引用（事件书目 / 关系定性），最多 50 条、id 唯一 |
| `truncated` | bool | 主结果（`items`，图谱另含 `edges`）是否因 `limit` / 硬上限被裁剪 |
| `snapshot_version` | str | 快照内容寻址版本，如 `v1-2978ceda7d15` |
| `data` | object | **工具专属出参**（V1.0.1 schema 原样保留） |
| `error` | object \| null | `{code, message}`，仅 `ok=false` 时非空 |
| `meta` | object | `returned` / `citation_count` + 工具专属计数（`total`、`limit`、`node_total` 等） |

真实返回示例（`toolkit.call("search_events", q="赤壁")`）：

## 3. 8 个工具

| # | 工具 | 入参（契约） | `data` 主字段 | `items` |
|---|---|---|---|---|
| 1 | `resolve_entity` | `query` / `era_id?` | `candidates[]` / `ambiguous` | 候选列表（人物或事件） |
| 2 | `search_events` | `q` / `dynasty?` / `year_range?` / `importance_min?` / `limit?` | `events[]` / `total` | 事件摘要 |
| 3 | `get_event` | `event_id` | 事件全字段 + `person_ids` / `source_refs` / `surface` | `[事件]` |
| 4 | `get_person` | `person_id` | 主数据 + 别名 / 分期 / `event_ids` | `[人物]` |
| 5 | `get_person_events` | `person_id` / `limit?` | `events[]` / `total` / `co_occurring_person_ids[]` | 事件摘要 |
| 6 | `get_relation` | `person_id_a` / `person_id_b` | 定性 + `shared_event_ids` / `basis_event_ids` / `attribution` | `[关系]` |
| 7 | `get_era_graph` | `era_id` 或 `scope_id` / `center_person_id?` / `limit?` | `nodes[]` / `edges[]` / `truncated` | 节点 |
| 8 | `timeline_span` | `start_year` / `end_year` / `limit?` | `events[]` / `total` / `representative_event_ids[]` | 事件摘要 |

### 3.1 `resolve_entity` —— 实体消歧

解析顺序：**精确姓名/别名 → 姓名子串 → 事件标题回退**；带 `era_id` 时按 `era_ids/scope_ids`（group 再按朝代）过滤。

```json
{
  "data": {
    "candidates": [
      { "person_id": "p-liangtaihou-handong-90be", "name": "梁太后", "disambiguator": "东汉·梁冀妹·顺烈皇后", "era_ids": ["qinhan"] },
      { "person_id": "p-liangtaihou-xixia-0d0f", "name": "梁太后", "disambiguator": "西夏·毅宗后", "era_ids": ["beisong", "xixia"] }
    ],
    "ambiguous": true
  },
  "items": ["…同上两条候选…"],
  "truncated": false
}
```

- 无上下文必须返回**全部**候选（≤10），`ambiguous=true`，**不默认取第一条**；
- `era_id="xixia"` → 只返回西夏梁太后；`era_id="qinhan"` → 只返回东汉梁太后；
- 别名「唐太宗」→ 李世民；无人名命中时「赤壁之战」→ `event_id=handong-chibi`；
- 查无 → `ok=false`、`ENTITY_NOT_FOUND`；未知时期 ID → `ENTITY_NOT_FOUND`。

### 3.2 `search_events` —— 事件检索

```json
{
  "data": {
    "events": [
      { "event_id": "handong-chibi", "title": "赤壁之战", "dynasty": "东汉", "year": 208, "importance": 3 }
    ],
    "total": 1
  },
  "truncated": false
}
```

- 关键词同时匹配标题（+20，精确 +100）、参与者（+10）、摘要（+5），按相关度 → 重要度 → 年份排序；
- 别名展开：`q="唐太宗"` 同时检索「李世民」，`meta.terms` 记录展开词；
- 支持 `dynasty` 精确匹配、`year_range={start,end}` 闭区间（含负数）、`importance_min`；
- **彩蛋事件默认排除**；空结果 `ok=true` + `total=0`；
- `limit` 1..80，超限 `INVALID_REQUEST`。

### 3.3 `get_event` —— 事件详情

```json
{
  "data": {
    "event_id": "xixia-09",
    "title": "灵州之战",
    "dynasty": "西夏",
    "year": 1081,
    "description": "宋五路伐夏，西夏梁太后坚壁清野，宋军围灵州十八日不克，粮尽溃败，死者十余万。（据《宋史·夏国传》）",
    "importance": 2,
    "is_special": false,
    "person_ids": ["p-gaozunyu-82de", "p-liangtaihou-xixia-0d0f", "p-liuchangzuo-bb63"],
    "source_refs": [{ "label": "宋史·夏国传", "book": "宋史", "raw": "（据《宋史·夏国传》）", "chapter": "夏国传" }],
    "source_status": "cited",
    "surface": { "timeline": true, "graph": true }
  },
  "items": ["…同上…"],
  "meta": { "fact_usable": true, "source_ref_total": 1 }
}
```

- 未知 ID → `ENTITY_NOT_FOUND`；格式非法 → `INVALID_REQUEST`；
- 彩蛋事件可显式读取，但 `is_special=true`、`source_refs=[]`、`meta.fact_usable=false`，回答层不得当史实引用。

```json
  "items": ["…同上…"]

```

- `citations` 取重要度最高的最多 5 条关联事件书目，供回答引用。

### 3.5 `get_person_events` —— 人物关联事件

```json
{
  "data": {
    "events": [
      { "event_id": "sui-09", "title": "晋阳起兵", "dynasty": "隋", "year": 617, "importance": 3 },
      { "event_id": "tang-01", "title": "建立唐朝", "dynasty": "唐", "year": 618, "importance": 3 }
    ],
    "total": 10,
    "co_occurring_person_ids": ["p-liyuan-1546", "p-duruhui-655f", "…共 17 人…"]
  },
  "truncated": true,
  "meta": { "person_name": "李世民", "total": 10, "limit": 2, "co_occurring_total": 17 }
}
```

- 事件按年升序；`co_occurring_person_ids` 按同现次数降序、`person_id` 升序（不含本人，≤80）；
- `limit` 裁剪只影响 `events`，同现统计始终基于全量事件。

### 3.6 `get_relation` —— 两人关系

```json
{
  "data": {
    "person_id_a": "p-dingruchang-4ff9",
    "person_id_b": "p-yidongyouheng-37bf",
    "label": "敌手",
    "shared_event_ids": ["qing-42"],
    "basis_event_ids": ["qing-42"],
    "attribution": "史脉关系库（人工校订）",
    "description": "黄海海战丁汝昌率北洋舰队迎战伊东祐亨，威海卫被围，丁汝昌拒降自尽。"
  },
  "items": ["…同上…"],
  "citations": [
    { "id": "cite-relation-丁汝昌__伊东祐亨", "kind": "relation", "relation_id": "丁汝昌__伊东祐亨", "title": "丁汝昌·伊东祐亨·敌手", "attribution": "史脉关系库（人工校订）" },
    { "id": "cite-qing-42-0", "kind": "event", "event_id": "qing-42", "title": "甲午战争", "source_ref": { "label": "清史稿", "book": "清史稿", "raw": "（据《清史稿》）" } }
  ]
}
```

- 关系记录存在：`shared_event_ids` = 两人事件交集，`basis_event_ids` = 关系库用于引用的共同事件（前者可大于后者，如严嵩×嘉靖帝）；
  **关系定性本身不带书目**，`citations` 只落到 `basis_event_ids` 的事件书目；
- 关系库无记录但两人有共同事件：`label="共同事件（关系库无定性记录）"`，`basis_event_ids=[]`，引用只来自共同事件；
- 无记录且无共同事件：`label="无直接关系记录"`、`citations=[]`，`ok=true`；
- 同一人 / 未知人物 → `INVALID_REQUEST` / `ENTITY_NOT_FOUND`；输入顺序保留在 `person_id_a/b`。

### 3.7 `get_era_graph` —— 时期图谱

```json
{
  "data": {
    "era_id": "xixia",
    "center_person_id": "p-liyuanhao-f692",
    "nodes": [
      { "person_id": "p-liyuanhao-f692", "name": "李元昊" },
      { "person_id": "p-fanzhongyan-060a", "name": "范仲淹" },
      { "person_id": "p-hanqi-fd58", "name": "韩琦" }
    ],
    "edges": [
      { "person_id_a": "p-fanzhongyan-060a", "person_id_b": "p-hanqi-fd58", "weight": 3, "relation_label": "同僚（边防）" },
      { "person_id_a": "p-fanzhongyan-060a", "person_id_b": "p-liyuanhao-f692", "weight": 2, "relation_label": "对手（边争）" },
      { "person_id_a": "p-hanqi-fd58", "person_id_b": "p-liyuanhao-f692", "weight": 2 }
    ],
    "truncated": true
  },
  "items": ["…nodes…"],
  "meta": { "node_total": 29, "edge_total": 46, "node_returned": 3, "edge_returned": 3, "limit": 3, "center_person_id": "p-liyuanhao-f692" }
}
```

- `era_id`（18 期）与 `scope_id`（7 组）**必须且只能提供一个**，否则 `INVALID_REQUEST`；
- 带中心：中心排第一，其后按边权降序取一跳邻居；不带中心：按快照节点顺序取；
- 节点上限 80（`limit` ≤80）、边上限 160；`truncated` 表示节点或边被裁剪；
- 未知时期 / 中心人物不在图中 → `ENTITY_NOT_FOUND`。

### 3.8 `timeline_span` —— 时间区间

```json
{
  "data": {
    "events": [
      { "event_id": "qin-unify", "title": "秦始皇统一六国", "dynasty": "秦", "year": -221, "importance": 3 },
      { "event_id": "qin-arms-treasure", "title": "收天下兵铸十二金人", "dynasty": "秦", "year": -221, "importance": 2 }
    ],
    "total": 5,
    "representative_event_ids": ["qin-unify", "qin-arms-treasure", "qin-commandery", "qin-emperor-title", "qin-standardization"]
  },
  "truncated": true,
  "meta": { "start_year": -221, "end_year": -221, "start_label": "前221年", "end_label": "前221年", "total": 5, "limit": 2 }
}
```

- 闭区间；负数为公元前，`0` 非法（→ `INVALID_REQUEST`）；
- `representative_event_ids` 从**全量区间**按重要度取 ≤10，不受 `limit` 影响；
- 彩蛋默认排除；空区间 `ok=true` + `total=0`。

## 4. 关键口径（实现即约定）

| 主题 | 约定 | 理由 |
|---|---|---|
| 事件重要度 | 快照 `importance` 缺失按 **2** 处理（输出也写 2） | 与前端 `importanceOf(event) = event.importance ?? 2` 一致；`importance_min=3` 只出 136 条关键事件 |
| 彩蛋事件 | `search_events` / `timeline_span` / `resolve_entity` 事件回退**默认排除**；`get_event` 可显式读取并标 `fact_usable=false` | 审核报告风险登记 P2「彩蛋混入史实数据」 |
| 空结果 | 检索类：`ok=true` + 空列表 + `total=0`；单实体查询：`ok=false` + `ENTITY_NOT_FOUND` | §9.1「空结果有明确语义」 |
| 截断 | `truncated` 只表示主结果被裁剪；引用超过 50 条静默截到 50（`meta.citation_count` 可见） | 避免把「引用多」误报成「结果截断」 |
| 引用 | 事件引用来自 `source_refs`（id=`cite-<event_id>-<idx>`）；关系引用来自关系库归属 + 共同事件书目；人物不单独造引用，只用其事件 | Q3/Q6：引用可回指事件、关系不新增书目、每条带 attribution/license |
| 关系回退 | 关系库无记录但事件有交集时，返回共同事件并显式标注「无定性记录」 | 关系库 639 对，共同事件对 1,898 对；只为 639 对编造定性会失真 |
| 图谱中心 | 中心 = 快照 `default_center_person_id` 或调用方指定；节点含中心 + 一跳邻居，边为选中节点间的边 | 与报告 §9.1「裁剪到上限 80 + 中心邻居」一致 |

## 6. 三处解释的批复与落地

1. **统一信封已写进 `tools-v1.schema.json` 的 `output`**（批复通过）：成功 / 失败用 `oneOf` 表达，`data` 保持原工具出参；`contracts/tools-v1.schema.json` 已重新导出，`export_contracts.py --check` 通过。
2. **`resolve_entity` 人物优先、事件标题回退**（批复完全同意）：同一查询不混排人物与事件候选。
3. **`get_relation` 无定性记录时只给共同事件（同框记录）**（批复赞赏）：不凭空捏造关系，`basis_event_ids=[]` 且 `attribution="史脉关系库（无人工定性记录）"`。
