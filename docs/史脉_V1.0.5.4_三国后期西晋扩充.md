- **淮南三叛**：王凌之叛（251，一叛）、毌丘俭文钦之叛（255，二叛）、诸葛诞之叛（257，三叛）为司马氏代魏过程中三次大规模军事反抗，本批拆分为三条独立事件，使三次叛变的因果链条清晰可查。

- **羊祜与陆抗**：二人在荆州边境对峙而以信义相待，《晋书》《三国志》裴注均有详载，为正史所载之君子之交，收入以补三国后期人物关系的文化维度。
- **太康之治**：占田制为西晋重要经济制度，《晋书·食货志》详载其内容，收入以补西晋前期的制度维度，非纯政治军事事件。
