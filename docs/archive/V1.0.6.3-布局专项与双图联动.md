# V1.0.6.3 · 右侧史引面板 Flex 自适应布局 + 双图联动专项补丁

> 版本：`1.0.6.3`
> 日期：2026-11-26
> 触发：用户在 `/ask` 实测发现右侧史引面板「上下比例严重失调」——
> 人物关系图被锁在小固定区域、四周留白巨大；时间轴轨道被压成扁平一条、下方事件详情卡却被拉得巨大；
> 同时聊天气泡底部没有「同时展开时间轴 + 人物图谱」的入口，内联文字关系树又把聊天记录撑得极长。
> 目标：**右侧面板严格 Flex 自适应；一句提问同时给出时间轴 / 人物图谱两个联动按钮；内联关系树默认折叠。**

---

## 一、四个痛点与根因

| # | 用户现象 | 根因（本轮定位） |
|---|---|---|
| 1 | 人物关系图：画布被锁在固定小区域、四周大白边；底部信息卡被拉成一条横杠 | `PersonGraph2D` 用 `max-height: 34%` 分配底部信息卡、`fillContainer` 又在测量高度 < 320px 时回退固定 520px；力导向图 `viewBox` 固定、节点分布半径与画布无关 → 图偏小、白边大 |
| 2 | 时间轴：轨道压成扁平一条，下方事件详情卡巨大却只有两行字 | 嵌入模式把上方 `stage` 写死 `flex: 0 0 50%`，标题 / Tab 吃完固定高度后轨道只剩 ~200px；轨道再按「宽高比」等比缩放 → 更扁；下方详情区 `flex: 1 1 50%` + 卡片 `flex: 1 0 auto` 被强行拉满 |
| 3 | 回答气泡底部没有「时间轴 + 人物图谱」双入口；一次只能看一个图 | 后端直答链路（`infer_actions_for_question`）只返回问题焦点一侧动作；前端 `resolveGuideFromTranscript` 也只取第一个动作 → 面板只能渲染单一视图 |
| 4 | 内联渲染文字关系树后，右侧面板不弹 / 必须点小字；聊天记录被树撑得极长 | 前端把「内联树」和「侧边面板」当成互斥状态；树本身由模型 markdown 原样渲染，没有折叠策略 |

---

## 二、修复方案

### 2.1 右侧面板严格 Flex 自适应（`/ask` + 两个 iframe 页面）

**左右分屏**（`frontend/app/ask/ask.module.css`）：

- `.workspaceLayout` 改为严格 `display:flex; flex-direction:row; height:100%`；
- 左对话 `.chatCard { flex: 1 1 60% }` 自适应剩余宽度；
- 右面板 `.copilotPanel { flex: 0 0 40%; width:40%; height:100%; flex-direction:column }`
  （`min-width:380px / max-width:760px` 兜底；
  中等屏幕退化为 50/50，≤720px 变成浮层铺满）；
- `.copilotFrameWrap { flex:1 1 auto; min-height:0 }` + iframe `height:100%` → iframe 永远填满面板剩余高度。

**人物关系图**（`PersonGraph2D` + `PersonGraph2D.module.css` + `graph/page.module.css`）：

- 画布容器 `.layoutFill .graphHost { flex:1 1 auto; min-height:0 }`，占面板剩余主要空间（约 70%+）；
- 底部「当前中心 / 人物关系」信息卡 `.layoutFill .panel { flex:0 0 120px; height:120px; max-height:120px; overflow-y:auto }`
  ——固定 120px、内容超长在卡片内部滚动，绝不撑满屏幕；
- `fillContainer` 直接采用 ResizeObserver 实测高度（不再在 <320px 时回退 520px）；
- 力导向图新增 **自动适配视图**（`fitViewToNodes`）：按节点实际包围盒（含半径 / 标签）计算 scale / translate，
  稳定后把整张图撑满画布、四周只留 4% 呼吸边距；滚轮缩放 / 空白拖拽平移 / ＋－⟲ 按钮保留，「复位」= 重新自动适配。

**时间轴**（`timeline/page.tsx` + `timeline.module.css`）：

- 上方 `stage`（标题 + Tab + 轨道）改为 `flex:1 1 auto` 占主区，轨道视口 `flex:1` 吃满剩余高度；
- 下方 `detailStage` 改为 `flex:0 1 auto; max-height:40%; overflow-y:auto`，卡片 `flex:0 0 auto`
  → 内容少时自然收缩、不强行拉伸；内容超长时只在详情区域内滚动；
- 嵌入模式不再做等比缩放：按实测宽高直接生成布局——
  - 水平最小间距按实际像素（18px）换算百分比，窄容器自动增加错层；
  - 垂直步长按可用高度反推（上限 64px），圆点垂直铺满轨道区域，不再是扁平一条。

### 2.2 一句提问同时下发时间轴 + 人物图谱动作（双图联动）

**后端**（`backend/agent/intent.py` + `validator.py` + `orchestrator.py`）：

- `infer_actions_for_question`（直答链路）：问题只命中一侧时，用快照真实关联补齐另一侧——
  - 命中事件 → 按事件 `participants`（叙事顺序）取第一位可解析人物，补 `graph.focus_person`；
  - 命中人物 → 按「重要性降序 → 本人为主角 → 年份升序」挑代表事件，补 `timeline.focus_event`；
  - 例：「玄武门之变」→ `timeline.focus_event[tang-04]` + `graph.focus_person[p-lishimin-7efd]`；
    「展示李世民的人物关系图」→ `graph.focus_person` + `timeline.focus_event[tang-04]`。
- `infer_actions_from_evidence`（证据管线）：只查到事件证据时用 `related_person_ids` 补人物动作，
  只查到人物证据时用 `related_event_ids` 补时间轴动作（全部来自工具真实返回，不伪造关系）。
- `AgentOrchestrator._pair_ui_actions()`：模型只给出焦点一侧动作时，用快照补齐缺的另一侧
  （只补缺、不覆盖模型动作，≤3 条），在 grounded / 收尾 / 对比兜底三条出口统一生效。

**前端**：

- `lib/agent-guide.ts` 升级为「联动目标集合」：`resolveAnswerGuideTargets()` /
  `resolveGuideTargetsFromTranscript()` 同时产出时间轴 + 人物图深链接（同一表面只取第一个）；
- 新增 `GuideActionButtons` 组件：气泡底部并排渲染
  `[ 查看人物图谱 ]` `[ 查看时间轴 ]`（纯文字，用户反馈去掉 emoji 图标），点击即切换右侧面板视图；
- `/ask` 副驾驶面板新增视图切换 tab（人物图谱 / 时间轴），与气泡按钮共用同一状态；
  自动展开逻辑重写为「新回答 turn 变化 → 无论如何展开」，不再受内联文字渲染影响；
- `AgentDrawer` 悬浮抽屉同样渲染双按钮：点击后跳转 `/ask?panel=<surface>`，
  完整对话页据此直接展开用户选择的视图。

### 2.3 内联文字关系树默认折叠

- 新增纯函数 `frontend/lib/relation-tree.ts`：保守识别「单根 + ≥2 个树形子节点」的关系树
  （必须出现 `├ └ │ ┬` 等连接符，普通正文 / 列表不误判）；
- `MarkdownMessage` 把代码块内 / 正文内的关系树替换为折叠卡片，默认只显示一句：
  **「已为您提取到李渊家族的 5 位核心亲属，请点击右侧展开图谱查看」**，
  可点「展开文字版」查看原文（信息不丢）；完整交互图在右侧史引面板呈现。

### 4.3 已知边界

1. 双图补齐使用**快照确定性匹配**，不调用模型：问题里没有任何事件 / 人物实体时仍然不弹史引（符合预期，不伪造联动）；
2. `streamed` 直答不附引用 / 证据，刷新后按纯 Markdown 恢复，旧会话不会自动展开面板（保持 V1.0.5.1 行为），
   但新回答一定会展开；
3. 内联树折叠支持两类模型输出：制表符家族树（`├ └ │`）与箭头式关系图（Mermaid / ASCII 边列表
   `A[李渊] --> B[李世民]`）；普通列表 / 表格 / 其他代码块不受影响；
4. 根节点只写了裸 ID（如 `C --> AE[李元礼]`）时无法得知家族名，折叠文案降级为
   「已为您提取到 N 位核心亲属……」。
