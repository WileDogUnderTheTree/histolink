## 附：如何复现/更新本索引

```powershell
# 1) 找到本机会话目录（按工作区分子目录）
Get-ChildItem 'C:\Users\wiledog\.dsh\sessions' -Directory
# 2) 解压单个会话（zstd 可用 anaconda3\Library\bin\zstd.exe）
zstd -d -o session.jsonl 'C:\Users\wiledog\.dsh\sessions\<workspace>\<session>\session.v4.jsonl.zstd'
# 3) Python 逐行解析 JSONL：type=session 取 cwd/createdAt；type=session/title 取标题；
#    type=user/message 取首条需求；type=tool/call 统计工具；type=turn/start 计轮次
```
