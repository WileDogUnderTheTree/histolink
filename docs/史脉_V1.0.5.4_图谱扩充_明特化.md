# 明（1368—1662，含南明）深度扩充：正史来源版

**来源标准**：以《明史》为正史主干，《明实录》《明会典》为明代官修一手史料，《国榷》《明史纪事本末》为私修史著，《明季北略》《明季南略》《万历野获编》等作旁证并标注；《明史》无传的人物（如吴承恩、宋应星、罗贯中）以地方志、本人著述或《录鬼簿续编》等为据，明确标注；小说演绎（如刘伯温神机妙算、"诛十族"细节）不采或降级。

**文化科技补注（含概念勘误）**：
- **"四大名著"提法是近代才定型**，明代通行的是"四大奇书"：《三国演义》《水浒传》《西游记》《金瓶梅》。《三国》罗贯中、《水浒》施耐庵（罗贯中编次）成书于元末明初，《西游记》现存最早世德堂本（1592），作者吴承恩说据天启《淮安府志》（《明史》无吴传，存争议）；《红楼梦》为清代曹雪芹著，不在明代。
- 李时珍《本草纲目》（《明史·方伎传》）、徐霞客《徐霞客游记》（《明史·方伎传》）、宋应星《天工开物》（1637，《明史》无传，据书本身）、徐光启《农政全书》（《明史》本传）。
- 心学后学：王艮创泰州学派，李贽著《焚书》（《明史·儒林传》）。
