## 4. 与任务卡的偏差（需评审确认）

1. **人物记录 1,058 ≠ 任务卡 1,061**：实现发现 3 组「别名本身也是事件参与者姓名」
   （明武宗/朱厚照、明神宗/万历帝、宋恭帝/赵㬎），按 `PERSON_NAME_ALIASES` 合并为同一人，
   避免同一历史人物拿到两个 `person_id`（正是 V1.0 要修的 P0 问题）。
   已在 `docs/person-same-name-report.md` §3 逐条列出并留责任人。
2. **书目标签 191 ≠ 任务卡 185**：任务卡的 185 只统计括注中的首个书目；
   本实现把并列书目（如「（据《旧唐书》《新唐书》）」）的第二本也作为独立标签。
   引用条目 823 与任务卡一致（「裴注引《襄阳记》」按 1 条计，`raw` 保留完整括注）。
3. **快照 `snapshot_version` 内容寻址**：`v1-<内容 hash 前 12 位>`，保证 `--check` 字节级稳定；
   `generated_at` 是 `snapshot.meta.json` 唯一每次变化的字段，`--check` 忽略它。
4. **只读闸门**：405 不依赖路由是否存在，由 `/api` 写方法中间件统一返回 envelope；
   为此 `ErrorCode` 新增 4 个 API 层枚举值（`INVALID_REQUEST` / `METHOD_NOT_ALLOWED` /
   `ROUTE_NOT_FOUND` / `SNAPSHOT_NOT_LOADED`），已写入 `contracts/README.md`。
5. **`vitest.config.ts` 告警**：前端包为 CJS，Vite 提示配置文件 ESM 语法；
   运行正常，后续可改 `.mts` 或调整包类型。
6. **网络依赖**：安装 `pinyin-pro` / `vitest` / `openapi-typescript` / `ajv`（pnpm）
   与 `pytest` / `httpx` / `jsonschema`（pypi；本机 Tsinghua 镜像 TLS 失败，已改用 pypi.org 直连）。
