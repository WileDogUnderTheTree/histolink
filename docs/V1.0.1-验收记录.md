## 6. TC-10 模型能力实测验收

- 模型 `Qwen/Qwen3.5-35B-A3B` 实测通过：连通性、JSON 模式、tool calling、SSE、中文回答、确定性。
- 关键数据：4 次 ping 延迟 2335–2764ms、total_tokens 174–184（思考模式基线 251，与用户实测 248 同量级）；
  `/api/agent/ping_llm` 真实返回 `latency_ms=2441`、`usage.total_tokens=175`。
- 关键发现：默认思考模式开销高，`max_tokens` 不限制 reasoning；`enable_thinking=false` 生效（16 tokens / 732ms）。
- V1.0.3 路线：tool calling 为主 + JSON 兜底；意图抽取默认关闭思考；长文解释按需开启并提高超时。
- 报告：[docs/spikes/modelscope-qwen3.5-35b-a3b-capability.md](spikes/modelscope-qwen3.5-35b-a3b-capability.md)。

## 8. 偏差与已知限制（评审确认项）

1. **人物 1,058 vs 任务卡 1,061**：3 组「别名本身也是事件参与者姓名」按别名表合并，避免同一人物两个 `person_id`；见同名报告。
2. **书目标签 191 vs 任务卡 185**：任务卡只统计括注首个书目，本实现把并列书目第二本也计为独立标签；引用条目 823 一致。
3. **受控 id 口径**：`selectedPersonId` / `onPersonSelect` 当前参数为图节点 id（姓名），`person_id` 迁移随关系库在 V1.1 完成。
4. **跨页动作 UI**：ActionBus 已有待确认队列，但确认按钮 UI 属 V1.0.4。
5. **深链接范围**：打开恢复与动作回写已生效；全量 URL 状态化 / 前进后退恢复属 V1.0.4。
6. **评测**：只跑 contract 模式；真实评分属 V1.0.3。
7. **模型**：默认思考模式延迟 / token 开销高；V1.0.3 按报告参数建议落地。
8. **CI**：本地 `verify.ps1` 为权威门禁；GitHub Actions 配置已同步，但 Push 后才会实际跑一次远端构建。
